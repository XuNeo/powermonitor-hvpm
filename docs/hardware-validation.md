# HVPM 硬件验收清单

本清单用于设备首次接入时逐项确认。模拟模式已验证不等于硬件可用；macOS 与真实 HVPM 目前都属于待验证项。测试情况如实记录：未执行的项目写"未测"，不填预想结果。

## 0. 总则

- 首次上电前 DUT（待测板）必须与 HVPM 输出端断开。先用适合的假负载/万用表验证输出与关断，确认正常后再接 DUT。
- 安全电压（即首次测试使用的电压）必须经车间主任确认，并与表计、假负载的额定参数匹配。
- 绝不直接对 DUT 施加 13.5 V 上限。软件允许范围 0.80 至 13.50 V 只是设备能力，不是 DUT 可承受范围。
- 每条用例记录：日期、主机系统、SDK commit（`1afab10eac4468bd54f0f2256a9ed870eb5346c4`）、固件版本、序列号。

## 4. 异常与恢复

| 检查项 | 预期 | 结果 |
| --- | --- | --- |
| 采集中拔 USB | 显式停止、保留已写数据、提示输出状态未知 | 未测 |
| 输出 unknown 流程 | 任何通信失败后输出进入 unknown，重新使能前必须先 OFF | 未测 |
| 重连 | 不恢复供电、不恢复采集，生成新录制而非覆盖 | 未测 |
| closeDevice 失败 | 不谎报断电成功；界面保留未知状态与错误信息 | 未测 |
| 录制回放一致性 | 保存后离线打开，统计与实时统计一致；异常退出的录制提示截断 | 未测 |

## 5. macOS 单独验收

macOS 安装、libusb 后端、USB 权限对话框、HVPM 通信均未实测，需在 macOS 12 或更高（x86_64/ARM64）上把第 1 至 4 节重跑一遍，并记录：Python 版本、pip 实际取到的 PySide6 wheel 标记、是否需要额外安装 libusb（如 Homebrew 的 libusb）、首次插拔时的系统授权结果。

## 6. 验收结论模板

每次硬件测试结束记录：

- 通过项 / 未通过项（附现象与日志）；
- 实测固件版本、序列号、安全测试电压与负载；
- 实测采样率与误差；
- 遗留风险与下一步；
- 测试人、日期。
