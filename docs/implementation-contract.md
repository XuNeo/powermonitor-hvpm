# Implementation contract

Scope: Monsoon HVPM main channel + simulator, PySide6 desktop, raw-data capture and analysis. Data/control structures live in `models.py`. This document records the module boundaries used by backend, storage and UI.

## AcquisitionController (`acquisition.py`)
Pure Python, no Qt dependency. Construct `AcquisitionController()` starts a single SDK-owning worker thread (no hardware access until a command). Methods:
- `request(action: str, **kwargs) -> None`: enqueue command. Actions: `scan(backend='simulator'|'monsoon')`; `connect(backend=..., serial=None)`; `disconnect`; `set_voltage(voltage_v=...)` (local staging only, requires output off and idle); `enable_output(confirmed=True)` (explicit confirmation mandatory); `disable_output` (cancel sampling, stop sample mode then off); `start(path=Path)` (requires connected, creates new capture only); `stop` (does NOT power off).
- `state: ControllerState`: immutable snapshot, with output strings `unknown/off/on`, connection `disconnected/connecting/connected/error`, capture `idle/starting/running/stopping/error`. Success only after commands return; on means command acknowledged, not physically measured. Errors emitted and preserved. Failed stop/off cannot pretend safe.
- `poll_events() -> list[ControllerEvent]`: drains control events (`state`, `devices` with list[DeviceInfo], `error` with str, `capture_finished` with Path). No sample batches in event queue.
- `recent_records() -> np.ndarray`: snapshot of last 10 seconds (50,000 samples), dtype SAMPLE_DTYPE; bounded memory, returns a copy. Updated at batch boundaries. Controller writes every original batch directly to CaptureWriter in worker, UI independently polls at 50 ms.
- `shutdown(timeout=3.0) -> bool`: request stop, best-effort off if output_owned, close device, join worker with timeout; bool means worker exited, NOT proof of physical off. UI must inspect output/error and handle failures. Worker daemon acceptable only with explicit unknown state/error on shutdown failure.

Each start makes a NEW capture directory; never overwrite prior records. Backend sampling carries a threading.Event cancellation token checked around reads and during startup. All SDK calls are serialized. Simulator starts off, real HVPM unknown. Start and reconnect NEVER enable output.

## Storage (`storage.py`)
- `CaptureWriter(path: Path, metadata: dict | None = None)` creates new directory, metadata.json, samples.bin, events.jsonl exclusively. Fields add format/version/sample_rate_hz/complete=False.
- `writer.append(batch: SampleBatch)` validate across batches and write all records; may raise on disk error. `writer.event(kind: str, payload: dict | None=None)` safe JSON. `writer.close(complete: bool=True)` flush/close/update metadata. `writer.sample_count`.
- `CaptureReader(path: Path, validate: bool=True)`: metadata dict, records readonly structured ndarray/memmap, warnings list[str], `time_bounds -> tuple[float,float]` (last sample + period; empty 0,0); `iter_chunks(start: float|None=None,end:float|None=None,chunk_size=100000)` includes sample supports overlapping [start,end), returns ndarray chunks.
- `export_csv(reader, destination: Path, start=None,end=None)` creates destination exclusively, streams ORIGINAL samples whose supports overlap window, all SI plus flags/dropped. Window boundary convention documented. No overwrite.
- `import_csv(source: Path, destination: Path)` streaming CSV of our format to new capture; strict headers/validation. UI need only native replay + CSV export, CSV roundtrip is test/CLI convenience.

## Statistics (`statistics.py`)
- `compute_statistics(records: np.ndarray | Iterable[np.ndarray], start: float, end: float) -> WindowStatistics`
- WindowStatistics fields: start_s, end_s, sample_count (supports overlap), valid_sample_count, valid_duration_s, coverage, mean_current_a, min_current_a, max_current_a, mean_voltage_v, mean_power_w, charge_c, energy_j, invalid_count, loss_unknown(bool), gap_count. Properties duration_s, charge_mah, energy_mwh. Values None when no valid support; valid requires finite current, voltage and product, and not INVALID/DEVICE_ERROR. LOSS_UNKNOWN contributes samples but marks result incomplete. GAP_BEFORE boundary flagged; never integrate beyond fixed 0.2 ms support.
- `compute_statistics` never reads reduced plot data, weights partial sample supports, uses per-record 0.2 ms duration. It runs in background for large selections.

## UI (`ui/` and `app.py`)
`MainWindow(controller=None)` injectable controller defaults to AcquisitionController. `app.main` supports `--demo` (default simulator; never real auto connect or enable), `--open PATH`, `--screenshot PATH` optional for automated screenshot. UI uses only above controller/storage/stats interfaces. Real connection manually initiated. Voltage enable confirmation required; off always reachable. New recording path chosen or auto-created under user's cache with visible path and retain recordings. Stop independent of off.

Waveform UI uses one Current plot rendered as two PlotDataItem objects, `current` and `current_envelope`: light surface #fcfcfb with current #2a78d6, dark surface #1a1a19 with current #3987e5. Normal wheel zooms reconstructed time, Shift+wheel zooms current, and left-drag rectangle zooms only the time axis while its X range becomes the statistics selection. Right-click restores prior X/Y zoom states. Follow latest, the read-only selection region, current-only cursor text and the paged raw table are unchanged. Voltage and power remain in raw data/statistics/CSV. No Greek symbols (use uA, not symbol; use delta in words).

Display-only reduction contract (`build_display_data`, `DisplayData`):
- The 5 kHz raw records, `.pmcap`, CSV and statistics are never reduced or copied for display; cursor, selection statistics and the raw table read original records only.
- Modes are `raw` and `aggregate`. When the visible record count is at most twice the logical pixel column count (no more than about two samples per column), raw mode sets the current line to every original point with invalid values replaced by NaN and explicit NaN breaks at gaps, and leaves the envelope empty. Aggregate mode maps visible time onto ViewBox logical pixel columns and emits one mean point per (segment, column) group for the current line plus a `[min, max]` point pair sharing one X for the envelope (`connect="pairs"`); pair endpoints equal the true within-column raw min and max, and pairs are never connected across columns.
- Continuous segments break on GAP_BEFORE, time deltas beyond the sample-period tolerance, non-finite values and INVALID/DEVICE_ERROR flags; LOSS_UNKNOWN still contributes its value. mean/min/max never span a segment, so a gap splitting one column creates separate groups and is never bridged. Partial first/last columns use only samples actually present, no zero fill or interpolation; empty columns are omitted.
- Both items use `setDownsampling(ds=1, auto=False)` and `setClipToView(False)`; there is no pyqtgraph `peak` saw-wave path and no implicit second downsampling. The envelope is the same current color with low alpha and width 1; the mean line uses `connect="finite"`, `antialias=False`. Pan/zoom re-aggregates from the new raw viewport. Reduction is chunked vectorized reduce-at over at most 100,000-record chunks plus a pixel-column merge, so peak memory is a fixed chunk plus column-sized arrays.
- `PowerPlotWidget.display_summary()` returns display-only diagnostics `{mode, raw_visible_count, envelope_pairs}` for benchmarks; it is not an input to statistics or export. The benchmark tools report curve count, display mode, raw visible count, current line points, envelope points and envelope pairs, and never assume a fixed number of curves.

## Regression boundaries
Core tests cover mathematical and file-format behavior. Backend tests drive the pinned SDK with raw packet fixtures and inject command failures. Qt tests exercise the real window with simulator or injected control state. `tools/gui_smoke.py` drives a complete native-window capture workflow; benchmark tools separate decoder, recording and plotting measurements.
